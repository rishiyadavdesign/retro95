# Retro '98 Portfolio

This copy is packaged for local use. Its images, fonts, Framer runtime files,
project pages, and audio are stored inside this folder.

## Start

Double-click `start-local.command`, or run:

```sh
python3 -m http.server 4173
```

Then open <http://127.0.0.1:4173/>.

The pages need a local server because browser security rules do not allow the
Framer modules to work correctly when `index.html` is opened directly.
